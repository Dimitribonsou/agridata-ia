À Propos de ce Projet

AgriData-AI est un projet de plateforme web d'entreprise inspiree par les missions de l'offre apprenti developpeur fullstack du Laboratoire Departemental d'Analyses - Jura (LDA39). Le projet est actuellement en cours de developpement avec donnees simulees.

Pour plus de details sur l'architecture, les principes de conception et les technologies utilisees, consultez le [README principal](../README.md).
